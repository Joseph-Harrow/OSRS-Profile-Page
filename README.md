# OSRS Profile Page

A practice webpage for displaying information about an Old School RuneScape (OSRS) profile via TempleOSRS (https://templeosrs.com/). The webpage is set up with HTML, CSS, and JS for interaction with a small server run in Node using Express.js that acts as a courier between the page and TempleOSRS's API.

## Skills

This project serves as a simple practice on API requests and back-end servers. Skills developed and practiced include:

* General HTML, CSS, and JavaScript practice for page setup, styling and interactivity.
* Creating a very basic server to serve a page.
* Using Fetch() to make API requests, both within the webpage JS to the server and from the server to the TempleOSRS API.
* Handling incoming requests on a server with Express.js routes.
* Asynchronous JavaScript use with async, await, and promise resolution
